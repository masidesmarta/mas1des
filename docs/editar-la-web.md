# Editar la web — guía para Marta

Tu web tiene un panel de edición. No hace falta saber programar: entras, cambias
textos o fotos, y le das a guardar. Los cambios aparecen en la web sola en un par
de minutos.

## Entrar

1. Ve a **tu-web.es/keystatic** (por ejemplo `mas1des.vercel.app/keystatic`).
2. Entra con tu cuenta de **GitHub** (la primera vez te pedirá permiso; es normal).

## Editar un proyecto

1. Pincha en **Proyectos** → elige el proyecto (o **New** para crear uno).
2. Rellena los campos. Los de texto vienen en **dos idiomas** (ES y EN): rellena
   los dos para que la web se vea bien en ambos.
   - **Título / Resumen / Descripción / Ubicación / Tipo / Rol** → en español y en
     inglés.
   - **Orden**: número. Menor = aparece antes en la lista.
   - **Destacado**: márcalo si quieres que salga en la portada.
   - **Carpeta**: en qué carpeta del escritorio aparece el proyecto
     (Académicos, Concursos, Visualización, Performance o Publicaciones).
   - **Descripción**: puedes poner **negrita** escribiendo `**así**` y *cursiva*
     con `*así*`. Separa los párrafos con una línea en blanco.
3. **Fotos**:
   - **Portada**: la imagen principal (sale grande arriba).
   - **Galería**: añade las que quieras con **Add**; puedes reordenarlas
     arrastrando.
   - Sube las imágenes **ya optimizadas** si puedes (la web las comprime, pero
     mejor no subir originales de 20 MB).
4. Cuando termines, arriba a la derecha: **Save**.

## Publicar

Al guardar, el cambio se registra y la web se actualiza sola en ~1-2 minutos. Si
no lo ves al momento, refresca pasado un rato.

## Consejos

- **Guarda a menudo**. Cada guardado es un punto al que se puede volver.
- Si te da miedo romper algo: no lo harás. Todo queda registrado y se puede
  deshacer. Ante la duda, avisa a Enrique.
- El aviso de "imágenes provisionales": déjalo marcado mientras una foto sea un
  recorte temporal; quítalo cuando pongas la definitiva.
